Container architecture

This page is served by a zero-dependency Python HTTP server packaged in a multi-stage, Alpine-based Docker image.

Dockerfile→ Stage 1: builder→ Stage 2: python:3.11-alpine→ Container :8080
  • Builder stage byte-compiles the code; only the result is copied to the final image.
  • Alpine Linux base keeps the image small (~50 MB) with a minimal attack surface.
  • Runs as a non-root user and exposes only port 8080.
  • A HEALTHCHECK polls /health so Docker knows the app is alive.
  • Shares the host kernel: isolated with namespaces, limited with cgroups.
